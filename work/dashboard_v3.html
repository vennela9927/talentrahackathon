Capacity bounds

Planning calculations from the editable Capacity tab in the combined workbook. Proposed replicas above the pool budget expose a negative connection headroom.

RPS and storage estimates use proposed assumptions. Storage excludes child/history rows, resumes, event payloads, WAL and backups. The connection budget is a ceiling for this configuration; adding API replicas without resizing the database would exceed it.
